# Screenshot capture checklist

No screenshots are included yet. The main [README screenshot table](../../README.md#screenshots) defines the expected filenames and content; add actual captures here when the native build is available.

Use a disposable demo account and an isolated seeded backend. Show genuine feature states rather than implying that placeholder media, unconfirmed rewards or unsynchronized workouts are verified server results. For tutorial screens, use reviewed/licensed media or retain the explicit missing-media state.

Before sharing:

- Remove or replace personal email, private notes, health data and identifying profile details.
- Use consented demonstration photos or clearly labeled synthetic fixtures for progress-photo comparisons; never use another user's private media.
- Hide development tools, notification payloads, keys, access tokens and signed URLs.
- Capture consistent resolution/orientation and device chrome; include both light and dark themes.
- Include populated screens plus one useful validation/empty/offline state.
- Check that labels, units, dates and progress values are readable at the embedded size.
- Add accurate alt text when embedding screenshots in the README.
- Capture a small-screen/large-text example for the capstone accessibility appendix.

These placeholders do not constitute visual, accessibility or device verification. Do not check secrets or actual private progress data into the repository.
